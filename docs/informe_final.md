# Informe final
## RedConecta Telecom S.A
### Objetivo del proyecto
- Explorar archivo proporcionado por la empresa
- Filtrar y exportar datos requeridos por las áreas de Soporte Técnico y experiencia de clientes
- Visualizar dashboard sobre desempeño de los trabajadores por región y servicio
### Metodología aplicada
- Extracción de datos
- Funciones separadas y retornadas en un main()
- Filtración de datos por medio de funciones
- Visualización de dashboard de desempeño por región y servicio
- Exportación de datos requeridos por RedConecta Telecom
### Resultados principales
- Archivos exportados a outputs/
- Dashboard guardado en su propia carpeta y mostrando en su ejecución
- Notebook documentado con las principales funciones
### Conclusión
- Extracción de datos completa
- Visualización de dashboard funcional
- Módulos con funciones reutilizables permite una mejor precisión de análisis
