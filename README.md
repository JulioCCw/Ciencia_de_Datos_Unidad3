# Ciencia_de_Datos_Unidad3
## Análisis Exploratorio y Dashboard - RedConecta Telecom S.A
### data:
- dataset_set_D_telecomunicaciones.xlsx -> excel que contiene los datos completo y sin filtrar con el que se realizara el ejercicio.
### outputs:
- Archivos generados tras exploracion y filtrado de analisis_operacional.py
  - soporte_tecnico.xlsx
  - experiencia_clientes.xlsx
### scripts:
- analisis_operacional -> contenedor de funciones que interacuan con el excel de origen y exportan excel de salida con datos espesificos
- dashboard.py -> Muestra el total de incidencias reportadas por region y por tipo de servicio
# Flujo de proyecto:
- Datos originales extraidos de dataset_set_D_telecomunicaciones.xlsx
- Salida de datos filtrada:
  - soporte_tecnico.xlsx
  - experiencia_clientes.xlsx
